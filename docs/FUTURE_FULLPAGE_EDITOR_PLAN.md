# Future Feature Plan: Full-Page Dedicated Poster Editor

## Overview
Transform the current modal/popup poster customization editor into a dedicated full-page experience (`/editor/[type]/[id]`) reminiscent of modern Apple TV and streaming suite interfaces.

## Key Design Goals
1. **Cinematic Center Canvas**: Bolder, larger live poster preview with glassmorphism and subtle lighting depth.
2. **Dedicated Control Sidebars**:
   - **Left Sidebar**: Available posters, clean posters, excluded posters tab, and custom URL importer.
   - **Right Sidebar**: Fine-tuning controls for logo positioning, scale, offset, rating badges, streaming logos, and custom labels.
3. **Responsive & Mobile First**: Dedicated tabbed navigation on smaller screens for seamless poster customization.
4. **Deep Linking**: Direct URL routing (`/editor/movie/123`) to allow bookmarking and easy state restoration.
